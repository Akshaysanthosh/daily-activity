# Daily activity

A small, automated GitHub Actions journal maintained for this account.
Entries are generated by a scheduled workflow, not a record of manual coding work.

## Schedule

The workflow attempts an update every day at **09:47 IST**, with backup attempts
at **17:47 IST** and **21:47 IST**. It records at most one entry per India calendar
day. It runs on GitHub, so no local computer needs to stay on.

Each successful update appends today's date to `activity.log` and commits it to
`main`. The account owner is the commit author; GitHub Actions is the committer.
The commit message explicitly identifies the update as automated.
There is no backfilling or alteration of historical dates.

## Controls

- Run now: **Actions → Daily automated activity → Run workflow**.
- Pause: open that workflow's menu and choose **Disable workflow**.
- Resume: choose **Enable workflow**.
- Change times: edit `.github/workflows/daily-activity.yml` (cron is UTC).

GitHub can delay or drop scheduled jobs, so uninterrupted daily coverage is not
guaranteed. Public repository schedules may be disabled after 60 days without
repository activity. If updates stop, check the Actions page and re-enable the
workflow if needed.

Only the repository's built-in `GITHUB_TOKEN` is used; no personal token is stored.

References: [GitHub scheduled workflows](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)
and [contribution criteria](https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference).
